# 可幸 · 22岁存档

这是可幸在22岁时，为目前的自己留下的一份阶段性存档。记录这个阶段的表达、自我理解、偏好、矛盾和仍然未知的部分；对当时状态与希望改变的方向分别保存。

## 存档的时间边界

“22岁”是这份快照的标签。过去的聊天属于形成这份档案的历史材料，不表示全部发生在22岁。后来有新的经历或变化时，另建阶段版本，保留旧版本；发现历史事实错误时记录更正，不静默改写。

当前公开的是表达层：一个用于代拟和改写中文微信消息的 Codex skill，采用口语、短句和自然补充，随对象和场景调整语气，并保留原意、条件和承诺范围。

生活记忆、自我模型与原文证据的完整档案保存在本地，不在这个公开仓库中。聊天风格只是存档的一部分，不能据此还原全部本人或替本人作决定。

## 使用

将仓库中的 `my-wechat-style` 文件夹放入自己的 Codex 技能目录。已有同名技能时先保留自己的版本，避免覆盖个人设置。

调用示例：

```text
用 $my-wechat-style 帮我回复这条消息：……

用 $my-wechat-style 把下面这段改成自然的微信语气，保留我的意思：……
```

有原稿时直接改写；没有原稿时，可补充聊天对象、关系熟悉程度和自己想表达的立场。默认给一版可复制的成稿；也可以要求更简短、更正式或少一点玩笑。

## 包含内容

- `my-wechat-style/SKILL.md`：风格规则、适用场景与改写检查。
- `my-wechat-style/agents/openai.yaml`：技能名称、简介和调用示例。
- `my-wechat-style/references/style-examples.md`：明确标注的新写场景示例。

这是公开去原文版，只保留抽象的表达规则与新写示例。真实聊天原句、联系人信息、日期、消息编号、来源哈希、个人档案及完整聊天记录均未包含。

这套规则呈现一种个人中文聊天风格，不代表安装者本人的历史经历，也没有经过模仿准确率评估。可以用本人提供的样文和明确反馈调整，保留针对具体对象的差异。

技能只生成供本人审阅的文本，不会自动联系他人、发送消息或访问聊天记录。它不依赖额外服务或模型接口。
